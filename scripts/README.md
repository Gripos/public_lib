# Скрипты

## `sync-collection.mjs` — автосинхронизация коллекции

Переносит заметки коллекции из Obsidian-хранилища в `public_lib/`, скачивает и
локализует обложки, нормализует артикулы. Одним запуском делает всё:

1. копирует `*.md` (кроме моделей бренда `Welly`);
2. вырезает блоки ` ```dataviewjs ` и добавляет `quartz-properties: false`;
3. нормализует `sku` до цифр для брендов `Kaido House` и `Mini GT`;
4. скачивает обложки с внешних URL в `public_lib/static/covers/` и переписывает
   `cover:` на локальный путь `covers/<файл>`.

### Безопасность (важно)

Скрипт **ничего не удаляет** — только добавляет и обновляет файлы. Если заметка
или обложка стала не нужна, удали её вручную. Так случайный запуск (например, с
неверным путём к источнику) не может ничего потерять.

### Как запускать

**Вариант 1 — кликабельный файл (Windows).** Двойной клик по `sync-collection.cmd`
в корне репозитория. Окно само откроется, покажет результат и не закроется, пока
не нажмёшь любую клавишу.

**Вариант 2 — терминал из корня репозитория:**

```powershell
npm run sync                 # синк в public_lib/ (без сборки сайта)
npm run sync:serve           # синк, затем сборка и локальный просмотр на :8080
npm run sync -- "D:\путь"    # синк из другой папки-источника
```

### Источник коллекции

По умолчанию берётся `D:\Github\MainObsidian\6. Коллекции`. Переопределить
можно так (по приоритету):

1. аргумент командной строки: `npm run sync -- "D:\путь\к\vault"`;
2. переменная окружения: `$env:COLLECTION_SRC = "D:\путь"; npm run sync`.

Кликабельному `.cmd` путь тоже можно передать первым аргументом:
`sync-collection.cmd "D:\путь"`.

### Что означают строки вывода

```
Collection sync: <источник>
Collection sync: 12 copied, 25 Welly skipped, 12 dataviewjs stripped
SKU: 3 normalized to digits (Kaido House / Mini GT)
Covers: 12 localized (0 downloaded), 12 local
Nothing is ever deleted by this script — remove stale files manually.
Done. All covers local.
```

Если какую-то обложку не удалось скачать, в конце будет строка
`Cover download FAILED (kept remote): ...`, а код выхода станет `1` —
просто запусти скрипт ещё раз, он повторит попытку.

> Сборка сайта после синка не запускается автоматически — используй
> `npm run sync:serve` или `npx quartz build` / `npx quartz build --serve`.
